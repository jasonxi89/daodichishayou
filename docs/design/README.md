# Handoff: 「到底吃啥哟」混血主题改版（御厨骨 × 贴纸肉）

## Overview
对微信小程序「到底吃啥哟」（Taro + React，仓库 jasonxi89/daodichishayou）的视觉与交互改版。方向为经用户多轮评审选定的**混血系统**：御厨纸感提供页面骨架与仪式感，贴纸漫画只用于动作与庆祝时刻。本包覆盖三个核心界面（首页、抽取仪式、结果页）+ 主题规则，食材页/菜谱弹窗/分享卡按同规则延伸（参考设计稿 2b/3b/3e）。

## About the Design Files
本包中的 HTML/PNG 是**设计参考稿**（浏览器 HTML 原型），不是可直接拷贝的生产代码。任务是在现有 Taro 代码库中，用其既有组件模式（页面 SCSS、`src/pages/index`、`src/pages/ingredient`、`src/components/*`）**重现**这些设计。样式值请以本 README 的 token 表与逐屏规格为准；HTML 稿用于核对视觉效果。

## Fidelity
**High-fidelity。** 颜色、字号、间距、圆角、文案均为最终定稿，应像素级重现（rpx 换算：设计稿基于 375pt 宽，1px = 2rpx）。

## 主题铁律（实现前必读）
1. **分工**：御厨（衬线、纸面、金线、印章）= 页面结构、标题、卡片、选择态；贴纸（粗描边、硬阴影、快乐体）= 只用于动作按钮、角标、抽取动画。
2. **emoji 只出现在「结果」里**（抽中的菜、签头图标），不进按钮、不做背景装饰。
3. **CTA 两级**：仪式类（为我定夺 / 再抽）= 墨块 #2f261a + 金字 #f0dfb8 + 两侧金线装饰；确认类（就它了！）= 贴纸黄 #ffb020 + 2.5px 黑描边 + 4px 硬阴影。
4. **倾角**。先分清两类旋转，本条只管第一类：
   - **装饰性倾角** = 静态的、纯为观感的 `rotate`。
   - **几何/动画旋转** = 为表现物理形态或动画过程而必需的 `rotate`（如签群扇开、摇签循环）。不受本条约束，但需在具体规格里写明。

   **默认档位**：装饰性倾角只能出现在贴纸角标上，取值 ±2° 或 ±6°。

   **具名例外清单**（穷举，不得类比扩展）：

   | 元素 | 角度 | 类别 | 依据 |
   |---|---|---|---|
   | 贴纸角标「天意如此！」 | **+4°** | 装饰性 | L57 逐元素规格 |
   | 印章「大厨认证」 | **-12°** | 装饰性 | L59 逐元素规格 |
   | 主签 | **-8°** | 几何 | L48，表现签从筒中斜出 |
   | 陪衬签 | **-18° / +4°** | 几何 | L48，表现签群扇开 |
   | 摇签循环 | **±2°** | 动画 | L48 状态机 |

   前两项是对默认档位的**显式豁免**：「天意如此！」用 +4° 而非 ±2/±6，印章虽非贴纸但允许装饰性倾角。两者皆以 `screens/4b-结果页.png` 观感为准。

   新增元素一律回到默认档位；需要新例外就改本表，不得口头放行。
5. 硬阴影（`Npx Npx 0 #1f1b16`）只给贴纸元素；御厨卡片一律柔和纸影 `0 10px 26px rgba(120,90,40,.08)`。

## Interactions & Behavior
- 菜单格：单选；点击切换选中墨块态，建议 0.15s ease 过渡 + 微弱 scale(0.97) 按压反馈
- 为我定夺 → 进入抽取仪式态（同页状态切换，非路由跳转）；抽取中点签筒 = 跳过动画直接出结果
- 结果页换一换：单行替换，替换行做 0.3s 淡出淡入；再抽 = 返回仪式态重抽；就它了 = 记录选择 + 触发分享引导
- 「更多 ▾」：菜单格下方展开剩余分类（同格式追加行），箭头翻转
- 需补状态：风向加载骨架（灰条 shimmer）、请求失败 toast（御厨语气：「厨房走神了，再试一次」）、空结果兜底
- 分享卡：替换现有 Canvas 绘制，按设计稿 3e「御厨手谕」样式重画（纸底、金线、壹贰叁菜单、印章）

## State Management
沿用现有 Taro 页面 state：`selectedCategory`、`servingCount`、`drawPhase('idle'|'shaking'|'rising'|'done')`、`results[3]`、`drawCount`（累计次数，本地持久化）。动画只做 class 切换，setTimeout 驱动 phase（摇 2000ms → 出签 500ms → 完成）。

## 落地注意
- 字体子集化：Noto Serif SC + ZCOOL 快乐体用 fontmin 按实际用字裁剪，`wx.loadFontFace` 或打包 base64；iOS/安卓 fallback 分别验证 900 字重渲染
- 44px 热区：换一换/步进器等视觉小按钮用 padding/hotspot 扩到 ≥44px
- 深色模式：本主题为纸面浅色，建议 `darkmode:false` 或后续单独出夜间纸色
- 工期参考：主题基建 1 天 → 首页 1.5 天 → 食材页 1 天 → 仪式动画 1.5–2 天 → 结果页+弹窗 1.5 天 → 分享卡 1 天 → 真机打磨 1 天（合计 7–9 天）
